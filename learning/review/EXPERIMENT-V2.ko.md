# Grok R1 이후 확장 실험 계획

이 계획을 확장 실험 실행 전에 작성했다. 기존 v1 결과를 이미 본 뒤 설계한 **탐색적 후속 실험**이며 독립 사전등록 연구라고 부르지 않는다.

- 기존 5가지 상황과 수치 생성 규약을 유지한다. 별도로 `ideal_quantity`(수량 0.6에서 최대 효용), `refund_saturation`(환불 0.4 이상에서는 효용 포화)을 추가한다. 실제 사용자 선호가 아니라 정해 둔 반례다.
- 정상·drift의 참 선형 가중치에 대해 주변 95% 구간 포함률을 보고한다. drift 포함률은 현재 취향을 놓치는 정도를 측정하는 진단이며 정적 모형의 명목 보장 검사가 아니다. 비선형 상황에 억지로 참 선형 가중치를 부여하지 않는다.
- 사용자 seed를 단위로 방법 간 차이를 짝지어 2,000회 percentile bootstrap, 95% 구간을 계산한다. 개별 테스트 쌍을 독립 사용자처럼 재표집하지 않는다. 정상/노이즈/분포변화/비선형/drift 모두 숨김 없이 보고한다.
- 질문 실험은 joint 정보이득, β를 조건부 적분한 w 정보이득, 임의 질문을 동일 후보·잠재 응답·사용자 seed로 비교한다. 기존 301~312 결과와 별도로 새 seed 501~524를 유지해 결과를 섞지 않는다. checkpoint 0/4/8/12를 모두 출력한다.
- 단일 endpoint는 새 seed의 질문 12회 log loss 차이로 정한다. 음수가 개선이다. 다중 비교·소표본·합성 모형의 한계를 명시하고, 우승 알고리즘을 실사용 기본값으로 자동 승격하지 않는다.
- 명시적 취향 변경은 원래의 대칭 사전분포로 새 epoch를 시작한다. 새 파라미터를 성능에 맞춰 고르지 않는다. 변경 직후 0개 응답의 순위가 균등 기준과 같은지 확인하고, 새로운 취향에서 8/24개의 새 응답을 넣은 경우를 별도로 측정한다.
- 새 결과를 보고 β/ε·특성 기준·위험 임계값을 다시 선택하지 않는다. 기존 개발 seed 1~12의 검증 절차를 그대로 사용한다. 결제 권한은 어떤 실험에서도 생기지 않는다.
