# Third-party notices

This implementation was informed by APReL's linear softmax response model, Bayesian belief structure, and information-gain acquisition formula. It uses a finite probability grid, not APReL's Metropolis–Hastings implementation. The application boundary, event handling, feature schema, decision-risk criterion and control rule are local implementation choices. No endorsement by the original authors is implied.

Reference code snapshots are retained only in the ignored research archive. The runtime does not import APReL or choix. We also reviewed choix's pairwise optimization implementation as an alternative. Their upstream notices are reproduced here for attribution.
