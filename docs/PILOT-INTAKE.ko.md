# 실제 사건·자료 접수와 비교 기록 양식

아래는 **빈 양식**이다. 실제 답변이 아니며 사람 수·고객 수·매출 증거로 집계하지 않는다. 회신 뒤 참가자에게 동의받은 내용만 기록하고, 기억나지 않는 값은 `미측정`으로 둔다.

## 참가 기록

| 항목 | 실제 답변 |
|---|---|
| 참가 코드 / 일시 / 담당자 | 미입력 |
| 실제 사람 확인 / 초면 여부 / 역할 | 미확인 |
| 응답 기록 동의 | 미확인 |
| 공개 발표에서 익명 요약·인용 허용 여부 | 미확인 — 기록 동의와 구분 |
| 진행 항목 | 미선택: 영상 이해 / 원문 검토 / 업무 사건 / 공급자 조건 |
| 시청 영상 SHA256·study ID 또는 작업 pack ID | 미입력 |
| 실제 원문 답변 저장 위치 | 미입력 |

연락처와 참가 코드의 연결표가 필요하면 응답 내용과 분리하여 접근을 제한한다. 기록을 원하지 않으면 참가를 강요하지 않는다. 자료 제공자가 공유할 권한이 없는 원문은 받지 않는다.

## 최근 실제 업무 한 건

1. 언제, 어떤 역할에서 무엇을 얻으려고 했나요? 실제 문서·주문은 어떤 것이었나요?
2. 직접 처리했나요, 외부 공급자에게 맡겼나요? 유료였다면 정액·호출·결과·외주 계약 중 어떤 방식이었나요?
3. 실제로 받은 산출물과 기대한 결과는 무엇이 달랐나요? 단순 장애, 잘못된 값, 누락, 지연을 구분해 주세요.
4. 어떻게 발견했고 검수·재요청에 얼마나 시간을 썼나요? 측정값인지 기억에 의한 추정인지도 구분해 주세요.
5. 실제 청구·환불·재시도는 어떻게 처리됐나요? 기존 기능으로 충분히 해결되었나요?
6. 기존 도구나 짧은 스크립트로 같은 일을 끝낼 수 있나요? 추가 지갑·검수 조건을 도입할 이유가 없으면 그대로 알려 주세요.
7. 다른 공급자와 합의할 수 있는 납품 기준·기한·실패 처리 조건은 무엇인가요?

답변 원문: **미수집**. 금액·시간: **미측정**. 원자료/자기보고 구분: **미확인**. 익명 공개 허용: **미확인**.

## 공유 가능한 자료 범위

선호 순서는 **이미 공개된 문서 링크 → 허가받은 최소 발췌 → 자료 없이 사건 설명**이다. 원문을 받기 위해 비밀정보를 요구하지 않는다.

- 제공자에게 권한과 사용 목적(내부 검증 / 모델 입력 / 공개 데모)을 각각 확인한다. 내부 검증 동의만으로 외부 모델 입력·공개 게시를 허용했다고 해석하지 않는다.
- 자료 제공자가 이름·메일·전화·계정/주문/고객 ID·서명·키·계좌·내부 URL을 제거하고 파일 메타데이터·주석·첨부·숨은 시트/텍스트도 확인한다. 검은 도형으로 덮기만 한 PDF는 삭제된 정보로 보지 않는다.
- 확인할 작업에 필요한 기간·행·부호·단위는 유지한다. 수치를 변형했다면 변형 여부와 검증 가능 범위를 표시한다. 변형본을 원래 고객 사건의 원자료로 간주하지 않는다.
- 수신 후에도 공개 전 사람이 재확인한다. 식별자를 지웠다고 재식별 불가능을 보증하지 않는다.

| 자료 항목 | 기록 |
|---|---|
| 자료 코드 / 제공 동의 / 허용 목적 | 미확인 |
| 공개 URL 또는 제한된 로컬 경로 | 미수집 |
| 원문 / 비식별 발췌 / 변형본 / 자기보고 | 미확인 |
| SHA256·문서 버전·확인 페이지 | 미입력 |
| 제거·변형 항목 / 검토자 / 일시 | 미입력 |
| 보관 기간·삭제 또는 철회 처리 약속 | 미합의 |

실제 자료는 Git 제외 경로 `data/private/pilot-intake/`에 저장하고 공개 후보·벤치마크 파일과 섞지 않는다. 파일이 접수되기 전에는 경로만 만든 것을 자료 확보로 세지 않는다.
