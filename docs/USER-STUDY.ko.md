# 실제 참여자 검증 절차

현재 상태: 실제 참여자 응답 없음. 자동 브라우저 검사와 페르소나 에이전트를 사람 3명으로 계산하지 않는다.

## 준비 자료

- 로컬 서비스 첫 화면: `http://127.0.0.1:3412/`
- 기록된 실행: `http://127.0.0.1:3412/?replay=1` (최신 기록 완성 후 사용)
- 참여자 질문지: `http://127.0.0.1:3412/?study=1`
- 원문: https://www.lgensol.com/upload/file/irEvent/25_4Q_LGES_business_performance_F_EN.pdf#page=16
- 원문 검토 대상: 시설투자 현금유출 2025 Q1 -3,014 / Q2 -2,717 / Q3 -2,171 / Q4 -2,515, 십억 원. 납품은 지출액을 양수로 정규화하고 원 부호도 보존한다.

링크는 실행 중인 PC에서만 열린다. 원격 참가자에게 localhost 링크를 보내지 않는다. 현장 PC 또는 화면 공유로 시청하고 질문지에 직접 답한다. 공개 게시나 사람에게 메시지 발송은 아직 하지 않았다.

## 초면 참여자 3명

1. P1, P2, P3 등 익명 코드를 부여하고 실제 참여임을 확인한다. 기존 팀원·프로젝트를 이미 검토한 사람은 초면 참여자로 세지 않는다.
2. 설명 없이 최신 데모를 한 번 보여준다. 관찰자는 정답이나 버튼 위치를 알려주지 않는다.
3. 사용자·문제, AI/코드의 역할, 환불/지급 이유, 남은 신뢰, 혼란 지점을 자유롭게 답하게 한다.
4. 관찰자는 각 답이 맞는 이유 또는 오해를 원문 인용과 함께 기록한다. 답안이 없거나 애매하면 이해 완료로 판정하지 않는다.
5. 오해가 반복된 화면을 수정하고, 수정 전/후 데모 버전과 관찰을 보존한다. 같은 사람이 다시 보는 경우 초면 참가자 수를 늘리지 않는다.

## 잠재 사용자 실제 문제 확인

리서치·유료 API·에이전트 업무 경험자가 겪은 **최근 실제 사건** 한 건을 받는다. 당시 작업, 잘못된 결과/재시도/검수 문제, 사용한 해결책, 직접 소요된 시간·비용을 구분한다. 기억나지 않는 수치를 유도하거나 만들어 채우지 않는다. 우리 제품이 필요 없는 이유와 기존 도구가 충분한 경우도 기록한다.

## 정답 표 사람 검토

최소 한 명이 원문 PDF의 표 머리글·연도·행·단위·음수 부호를 직접 확인하고 일치/차이를 답한다. Codex의 시각 확인만으로 `human_review=COMPLETE`로 바꾸지 않는다. 공급자 공개 문서와의 일치를 검토하는 것이며 발행사의 수치 자체를 외부 감사하는 것이 아니다.

## 기록과 완료 기준

- 응답은 해당 실행 디렉터리의 `human-study/responses.jsonl`에 저장된다. 개인 연락처를 수집하지 않는다.
- 실제 사람과 자동 QA는 `participant_kind`로 분리한다. 참가 코드별 마지막 응답을 집계한다.
- 응답에는 시청한 기록 파일의 SHA256이 포함된다. 수정된 데모를 과거 응답으로 검증했다고 주장하지 않는다.
- 사람 3명의 실제 응답·이해 관찰, 잠재 사용자의 실제 사건, 원문 표 사람 검토가 있어야 이 단계의 완료를 판단한다. 폼이나 영상 완성만으로 완료가 아니다.

## 텍스트로 전달할 수 있는 참여 안내 초안

“에이전트가 자료를 구매할 때 결과와 지급을 검증하는 데모를 테스트하고 있습니다. 약 5~10분 동안 영상을 보고, 이해한 내용과 헷갈린 부분을 답해 주세요. 익명으로 기록하며 연락처나 회사 비밀은 받지 않습니다. 실제 리서치·유료 API 업무 경험이 있다면 최근 겪은 관련 문제도 듣고 싶습니다.”

이 안내는 초안이며 누구에게도 발송하지 않았다.
