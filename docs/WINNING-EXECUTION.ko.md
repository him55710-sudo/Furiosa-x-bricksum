## AI가 하는 일과 하지 않는 일

새 원문의 단순 추출은 코드가 **188ms, 모델 0회**에 같은 네 값을 얻었다. 모델 추출은 **20,096ms, 8,253토큰**이었다. 따라서 기본 추출은 코드다. [원문 평가](../artifacts/deal-escrow/research/source-evaluation/report.json)는 지원하지 못한 두 문서와 한 문서의 파서 수정도 남긴다. 같은 발행사의 한정된 표 문법이며 임의 PDF 검증이 아니다.

AI는 자연어 견적이 실제 분기 실적·주문한 지표에 해당하는지 판정하고 원문 문장 ID를 제시한다. 코드가 근거 ID를 검증해 인용을 재구성하고, 승인 범위 내 적격 견적의 공개 최저가·기한을 비교한다. 최종 원문 검사와 금융 권한은 모든 비교군에서 같다. 모델에는 실행 시점 날짜를 제공해 2025년 실적을 미래라고 오판한 오류도 고쳤다.

[AI 개발 재평가](../artifacts/deal-escrow/research/benchmark-2026-09-28T17-02-12-526Z-holdout-reviewed-live/report.json)와 이후 [강화 규칙 재평가](../artifacts/deal-escrow/research/benchmark-2026-09-28T17-26-49-975Z-holdout-strong-fixed-offline/report.json)를 함께 본다. 각 실행은 8개 상황 × 2회이며 실행 중 소스 변경 없음. [대조 자료](../artifacts/deal-escrow/research/benchmark-comparison-v2.json)는 사례 전체와 참조 문서 digest가 동일함을 검사했다. AI 결과는 이전 기록을 재사용하며 동시 측정이나 신규 모델 실행이 아니다.

**강화 규칙도 모델 호출 없이 같은 결과를 얻었으므로 이 집합은 AI의 추가 가치를 입증하지 못한다.** 규칙 v2는 시설투자·현금 지출의 표현, 월별 분기 표기, 제한된 부정문 처리를 추가했다. 기대 정답·납품 종류·샘플 숫자는 견적 선택 입력에 주지 않으며 가격·기한·최종 검수는 동일하다.

규칙과 AI 모두 알려진 사례를 보고 개선했다. 미공개 평가나 100% 신뢰도의 근거가 아니다. 실패 이력은 AI 경로끼리 비교할 때 호출 2회와 토큰 2,760개를 줄였으나 강화 규칙보다 효율적이라는 뜻은 아니다. 전력 절감·GPU 대비 RNGD 우위는 측정하지 않았다. Kiln 호출 성공을 하드웨어 이용률 증거로 쓰지 않는다.

## 이제 해야 할 일 — 심사 가치를 기준으로

1. **실제 문제 한 건을 확보한다.** 외부 유료 데이터 작업에서 최근 발생한 오납품·재요청·청구 문제의 원자료를 받는다. 기존 도구로 충분히 해결되면 업무 가설을 수정한다. 이 네 값을 우리가 즉시 추출하는데 왜 유료 공급자와 에스크로가 필요한지 답하지 못하면 제품 설득력이 약하다.
2. **구매자와 공급자 양쪽에서 작은 파일럿을 한다.** [조건 초안](SUPPLIER-PILOT-TERMS.ko.md)을 실제 상대가 수용하는지 확인한다. 성공 기준은 한 작업의 쓸 만한 납품, 검수 시간, 재작업, 비용이다. 모의 공급자를 실제 거래 상대라고 부르지 않는다.
3. **수정에 쓰지 않은 작업에서 비교한다.** 외부가 작성한 사례와 더 강한 규칙/기존 업무 방식으로 품질·총 지연·토큰·실제 사용 비용을 비교한다. 성공만 보고서에 넣지 않는다. 현재 테스트 집합 재실행을 늘리는 일은 후순위다.
4. **3분 데모를 초면 3명에게 검증한다.** 제품 사용자, 지급/환불 이유, 다음 거래의 변화, 남은 검수자 신뢰를 설명 없이 이해하는지 확인한다. 사람 원문 검토도 함께 받는다. [참여자 절차](USER-STUDY.ko.md)를 사용하고 실제 답변만 기록한다.
5. **대회 기여를 측정 가능한 문장으로 고정한다.** Kiln의 실제 판단, 불필요한 호출 감소, 공개 체인의 앱 독립 환불을 각각 증거로 제시한다. 하드웨어/전력 수치는 제공된 계측이 있을 때만 쓴다. 발표에서는 제품 문제 → 정상 결과 → 그럴듯한 오납품 → 다음 거래 변화 → 앱 없이 회수 순서를 유지한다.

2026-09-29 [연결 후보·업무 자료 묶음](PILOT-DISCOVERY.ko.md)을 추가했다. 공식 공개 연결 경로 5개, 공개 문제 사례 3건, TAT-QA 외부 작성 작업 12개, 정답을 분리한 전달용 자료와 연락 초안을 확보했다. 공개 자료는 고객이 제공한 익명 업무나 미공개 평가가 아니며 현재 CAPEX 자동 검수에 연결하지 않았다. 연락은 미발송이고 실제 참여자·고객 작업·공급자 수락은 여전히 없다. 다음 행동은 후보에게 최근 사건과 조건 수용 여부를 확인하고 실제 응답을 받는 것이다.
