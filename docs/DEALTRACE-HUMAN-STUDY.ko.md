# 초면 사용자 3명 이해도 검증

상태: **미실시. 실제 응답 0명.** 구현과 자동 화면 검증을 사람의 평가로 세지 않는다.

서로 답을 공유하지 않은 초면 참가자 세 명에게 `artifacts/dealtrace/film-v3/dealtrace-3min.ko.webm`을 한 번 보여준다. 버전은 공개 실행 `34d1da0d-e842-4f44-acfd-4d97728c81f0`의 저장 기록이다. 진행자는 영상을 보여주기 전에 정답을 설명하지 않는다. 참가자의 신원이나 연락처는 수집할 필요가 없다.

영상 직후 아래 세 질문에 자유롭게 답하도록 한다.

1. 누가 어떤 일을 할 때 이 제품을 쓸까요?
2. 예산이 40인데 청구 31을 왜 막았나요?
3. 26을 지급해도 된다는 근거는 무엇이었나요?

추가로 기록 화면을 2분 동안 탐색하게 한 뒤, 원 메시지·확정 거래·납품·청구·실제 거래 중 어떤 기록을 근거로 삼았는지 묻는다. 찾지 못한 항목과 이해하지 못한 표현도 그대로 적는다. 이 후속 확인을 영상 직후 응답과 섞지 않는다.

익명 기록 양식:

```text
참가자: P1 / P2 / P3
일시:
기존 프로젝트 설명을 들은 적: 예 / 아니오
본 버전: film-v3 / 공개 run 34d1da0d
질문 1 원문 응답:
질문 2 원문 응답:
질문 3 원문 응답:
기록 탐색 후 근거로 지목한 항목:
막힌 부분 / 받은 도움:
```

평가는 원문을 보존한 뒤 별도 열에 적는다. 대상 사용자·업무를 짚었는지, 예산과 합의 금액을 구분했는지, 양측 확인·인간 권한·납품 검수·일치하는 청구가 지급 근거임을 이해했는지를 각각 확인한다. 세 명이 모두 핵심 이유를 재구성하지 못하면 UI나 설명을 수정하고 새 버전으로 다시 확인한다. 세 명의 성공도 시장 수요나 일반적 사용성의 증거로 확대하지 않는다.
