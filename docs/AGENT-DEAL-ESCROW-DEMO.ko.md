# 3분 녹화 대본 — 실제 기록 재생

현재 녹화는 실제 Kiln 6회와 로컬 devnet 거래를 바탕으로 한 **기록 재생**이다. 공개 Sepolia 시연 또는 실시간 실행으로 소개하지 않는다. 화면 상단에 이 구분이 항상 표시된다. 라이브 실행은 Overview에서 새 mandate를 승인하고 협상→fund→delivery 버튼으로 수행할 수 있다.

`pnpm ade:build`, `pnpm ade:start` 후 http://127.0.0.1:3402/?replay=1 을 열고 재생한다. `pnpm ade:record`는 180초 재생을 무음 WebM으로 기록한다. 내레이션은 아래 대본을 사용한다. 실제 기록값을 바꾸거나 가짜 거래 해시로 교체하지 않는다.

## 녹화 전 점검

실제 실행을 다시 하면 금액·기한·토큰이 달라질 수 있으므로 화면의 최신값에 맞춰 대본을 읽는다. 성공·실패는 각각 별도 3.00 단위 mandate다. 동일 task 예산을 자동으로 올리지 않는다. 테스트 결과는 Node 출력 파일에서 표시되고 원본 지문이 다르면 오래된 실행으로 다뤄야 한다.

공개 테스트넷 녹화는 무료 Sepolia test ETH가 전용 지갑에 들어온 뒤 `pnpm ade:sepolia`로 별도 실행한다. 정상 fund/release/refund 결과를 확인하기 전에는 로컬 devnet 라벨을 바꾸지 않는다. 공개 explorer가 없는 로컬 devnet에는 가짜 explorer 링크를 만들지 않는다.
