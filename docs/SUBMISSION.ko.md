2026-09-29. 제품 코드는 유지하고, 완료된 결과를 짧게 이해하고 직접 확인할 수 있도록 정리했다. 프로토타입 구현과 작성된 시나리오 검증은 완료했으며 실제 고객 검증·실전 운용 완료를 뜻하지 않는다.

## 바로 볼 자료

- [한국어 2쪽 소개 PDF](../output/pdf/Agent-Deal-Escrow-brief.ko.pdf): 사용자, 문제, 핵심 흐름, 실제 화면, 검증 결과와 남은 신뢰를 쉬운 말로 설명한다. 한글 글꼴을 포함했고 두 페이지를 이미지로 렌더링해 확인했다. 공개 지급·환불과 저장소 링크 3개를 담았다.
- [휴대용 데모 ZIP](../output/submission/Agent-Deal-Escrow-demo.zip): 압축을 모두 풀고 `index.html`을 연다. API 키·지갑·패키지 설치 없이 저장된 기록을 본다. 브라우저가 로컬 파일을 제한하면 해당 폴더에서 `python -m http.server 3419 --bind 127.0.0.1`을 실행하고 `http://127.0.0.1:3419/`를 연다. 외부 GitHub·Sepolia 링크만 인터넷이 필요하다.
- [ZIP 해시](../output/submission/Agent-Deal-Escrow-demo.sha256), [패키지 검사](../output/submission/package-check.json), [브라우저 검사](../output/submission/browser-check.json). ZIP 내부 `manifest.json`은 나머지 57개 파일의 경로·바이트·SHA-256을 연결한다.

포함 자료는 최종 가상 실행의 HTML·영수증·보고서, 2쪽 PDF, 기존 공개 실증의 180초 무음 영상과 한국어 대본, 별도 Sepolia 지급·환불·구매자 회수 기록, 현재 102개 검사 원본과 Ubuntu CI 원본이다. 개별 실행의 원본은 바이트를 유지한다. 과거 manifest에 등장하는 제작기·폰트·소스 경로는 원래 저장소 경로이며 패키지 내부 파일 목록과 구분한다. 처음 실패한 가상 실행은 [저장소 보고서](FICTIONAL-DEMO-VALIDATION.ko.md)에서 계속 공개한다.

## 실제 자료가 필요한 항목

| 남은 검증 | 필요한 자료 | 현재 상태 |
|---|---|---|
| 사용자가 실제로 필요한가 | 발주자의 최근 오납품 사건과 공급자 참여, 유료 대안과 비교 | 인터뷰·실사용 미실시 |
| 처음 본 사람이 이해하는가 | 데모를 본 제3자의 설명과 영수증 재구성 관찰 | 참여 절차 구현, 사람 응답 0 |
| 처음 보는 문서에서도 맞는가 | 모델 수정 전에 동결한 새 문서와 독립 검토 정답 | 같은 파서의 공통 오류 가능성 남음 |
| AI가 더 유리한가 | 같은 안전 경계에서 시간·비용·성공률 비교 | 정상 협상 복구는 확인, 최저가·전반적 우위 미입증 |
| NPU가 전력을 얼마나 줄이는가 | 제공자의 장비·전력 측정값 또는 계측 접근 | 흐름별 토큰 기록·가정 계산 있음, 실측 없음 |

이 자료를 가상 응답으로 채우지 않았다. 위 항목은 출시 주장에 필요한 후속 검증이며, 이번 제출 자료 제작이나 가상 데모 실행을 막는 미구현 기능은 아니다. 운영자 신뢰, 공동 파서, 가스 경제성 때문에 실전 수탁 서비스로 표시하지 않는다. 공식 제출·PR 병합·고객 연락은 수행하지 않았다.
