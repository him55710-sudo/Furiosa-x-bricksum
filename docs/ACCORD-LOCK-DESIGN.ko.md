# accord lock — 거래 데모 디자인

2026-09-29. 현재 제품 기획의 구매자 예산, 정책 승인, 에스크로, 검수, 지급·환불 흐름을 중심으로 웹 콘솔을 새로 디자인했다.

- 브랜드: **accord lock**. 코발트 `#2454ED`, 화이트, 밝은 회색 표면. 판매 에이전트는 블루, 소비 에이전트는 레드로 구분한다.
- [토스](https://toss.im/)의 여백, 큰 제목, 친근한 문구, 둥근 표면, 입체 그래픽을 참고했다. 로고와 에이전트 캐릭터는 이 프로젝트용 CSS 그래픽이다.
- 메인 화면: 두 에이전트 사이에 금액 잠금과 데이터 이동을 표현한다. 재생·일시정지·처음으로·다음 단계·1/2배속·단계 직접 선택을 지원한다.
- 세 가지 시나리오: 정상 지급(180 gwei), 납품 실패 환불(30 gwei), 한도 초과 차단(201 gwei). 공개 실행 JSON에서 금액·판매자·이벤트·시간을 가져온다. 하단 예산은 재생 단계와 구분한 최종 실행 시점의 스냅샷이다.
- 말풍선은 설명용 재구성이며 모델 대화 원문이 아님을 화면에 표시한다. 새 거래나 지갑 연결 없이 기존 공개 기록을 재생한다. 원본 영수증과 탐색기 링크는 기존 상세 화면에 연결한다.
- 320px, 390px 모바일과 데스크톱에서 확인했다. 모바일 전체 메뉴, 키보드 포커스 복원, `prefers-reduced-motion` 처리를 포함한다. 시연은 사용자가 재생 버튼을 눌러야 시작한다.

## 실행과 파일

`pnpm ade:spending:view` → `http://127.0.0.1:3440`

- `web/spending/accord-scene.mjs`: 거래 장면, 시나리오 상태, 재생 제어.
- `web/spending/accord.css`: 새로운 브랜드와 반응형 디자인.
- `web/spending/app.mjs`, `index.html`, `favicon.svg`: 기존 화면 연결, 탐색과 브랜드.
- `artifacts/accord-lock/accord-lock-preview.html`: 외부 데이터 요청 없이 볼 수 있는 대화용 미리보기.

## 검증 범위

- 공개 사이트 빌드 성공, 두 JavaScript 모듈 구문 검사 성공.
- `node --test tests/deal-escrow/spending-site.test.mjs`: 8/8 통과. 배포 허용 목록에 CSS와 장면 모듈 2개가 추가되어 예상 파일 수를 갱신했다.
- 브라우저에서 세 시나리오 전환, 지급까지 자동 재생, 단계 선택, 영수증 열기·닫기, 기존 거래 상세 연결, 모바일 메뉴, Gwei/ETH 표시를 확인했다. 브라우저 오류 없음.
- 대화용 미리보기에서도 시나리오 전환과 차단 결과를 확인했다.

기존 엔진·계약·거래 기록은 변경하지 않았다. 이 디자인은 로컬에 반영한 결과이며 기존 공개 배포와 영상은 이전 버전이다. 세부 감사 화면에는 기존 영문 기술 설명이 남아 있다.

## 3분 발표 UX 보완

후속 요청에 따라 `#demo`에 여섯 장면의 180초 전용 시연을 추가했다. 자세한 타임라인과 대본은 [3분 시연 가이드](ACCORD-LOCK-DEMO-3MIN.ko.md)에 있다.

- 구매할 작업을 처음부터 PDF → 설비투자 데이터 표로 구체화했다. 원본 문서, 결과물, 지갑, 서명한 권한, 스마트 계약, 앱 종료 상태를 CSS 일러스트로 연결했다.
- 거래 장면의 위쪽은 에이전트의 작업·검수, 아래쪽은 온체인 자금 이동이다. 실제 예치·지급·환불 링크를 해당 단계 이후에 보여준다.
- AI의 제안, 오프체인 정책·검수, 계약의 한도·자금 집행을 구분한다. 앱 종료 후에는 구매자가 기한 이후 직접 환불을 요청했다는 사실을 표시한다.
- 상단 장면 선택, 180초 위치 슬라이더, 정지·재개, 키보드 조작, 종료·재시작을 제공한다. 증거를 열거나 탭을 벗어나면 재생을 멈춘다.
- `web/spending/accord-tour.mjs`는 시간과 장면을, `accord-tour.css`는 발표용 배치를 담당한다. 이전 대화용 미리보기 파일은 최초 홈 화면 디자인이며, 최신 3분 시연은 로컬 앱에서 확인한다.
- `node --test tests/deal-escrow/accord-tour.test.mjs tests/deal-escrow/spending-site.test.mjs`: 12/12 통과. 시간 경계, 실제 거래 링크의 공개 시점, 차단된 금액과 계약 예산 구분, 환불 기록 연결을 검증했다.
- 브라우저에서 실제 180초 자동 재생 후 `03:00 / 03:00`, 마지막 장면 유지, 재생 정지를 확인했다. 재시작, 구간 이동, 영수증 열기 시 정지·복귀를 확인했고 브라우저 오류는 없었다.
- 1280×720의 17개 주요 시점을 확인해 설명·증거 영역이 하단 제어판에 가려지지 않도록 수정했다. 1920×1080 발표 화면과 390px·320px 모바일을 확인했으며, 모바일에는 세로 스크롤과 가로 스크롤 가능한 장면 메뉴를 제공한다.

설계 검토와 브라우저 검증을 수행한 결과이며, 실제 관객 대상 이해도 테스트를 대신하지 않는다.
