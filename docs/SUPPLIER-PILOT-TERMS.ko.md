# 구매자·공급자 파일럿 조건 초안

상태: 외부 구매자·공급자에게 보내지 않았으며 실제 동의나 서명이 없다. 테스트 자산을 쓰는 소규모 시험 제안이다. 현재 UI의 공급자는 로컬 시뮬레이터다.

2026-09-29 [연결 후보·업무 자료 묶음](PILOT-DISCOVERY.ko.md)을 준비했다. 공개 연결 경로 5개, 공개 문제 사례 3건, 외부 작성 재무 QA 12개와 [후보별 연락 초안](PILOT-OUTREACH.ko.md)이 있다. 자료 탐색은 진행됐지만 연락·동의·실제 고객 사건 접수는 아직 없다. 외부 QA는 현재 CAPEX 자동 검수 범위 밖이다.

## 먼저 확인할 작업

구매자가 최근 외부 작업자에게 맡겼던 문서·데이터 작업 한 건을 익명으로 받는다. 당시 산출물, 검수·재요청에 쓴 시간, 실제 청구 방식과 환불 절차를 확인한다. 구매자가 직접 실행하는 간단한 코드로 같은 일을 충분히 끝낼 수 있다면 그 작업을 에스크로 수요의 증거로 세지 않는다.

구매자와 공급자 양쪽이 아래 조건을 읽고 수락한 사실을 받아야 참여 완료다. 에이전트 페르소나의 찬성, 생성된 계약 문구, 로컬 데모 키는 수락 증거가 아니다.

## 주문 전에 정할 조건

| 조건 | 현재 시험에서 제안하는 범위 |
|---|---|
| 산출물 | 지정 문서의 지정 연도·행에 대한 네 분기 값, 원 부호·단위·문서 해시·페이지·셀 식별자 |
| 원문 | 양측이 같은 PDF 버전과 허용 파서 범위를 확인. 자동 검사 불가능한 문서는 거래 시작 전 보류 |
| 가격·마감 | 승인한 최종 가격과 납품 기한을 주문에 고정. 최저 수용가 공개는 실제 판매자의 선택이며 필수 협상 모델로 가정하지 않음 |
| 지급 | 네 분기 전체가 사전 고정한 검사에 통과할 때만 테스트 대금 지급 |
| 실패·만료 | 검사 실패 시 환불. 미납품은 기한 만료 후 구매자가 직접 회수 가능. 이미 확정된 지급은 취소할 수 없음 |
| 재거래 샘플 | 해당 공급자의 검증된 실패 이후 한 분기만 사전 제출. 샘플 통과와 전체 납품 통과는 별도 |
| 검수자 | off-chain controller를 신뢰한다는 점을 양측에 설명. 원문 자체의 진실성·악성 검수자 방어를 보증하지 않음 |
| 이의 제기 | 파일럿 담당자가 원문·검사 로그를 함께 검토. 자동 중재나 일방적 지급 취소가 구현됐다고 약속하지 않음 |
| 비용 | 작업 대금, 추론 비용, 체인 가스를 분리 기록. 데모 가격을 실거래 가격으로 사용하지 않음 |

실패 환불된 주문은 임의로 재개하지 않는다. 수정 재의뢰는 남은 승인 예산과 통제 조건을 다시 만족해야 한다.

## 실제 응답으로 채울 기록

- 구매자 사건: 미확보. 원자료 또는 당사자 설명, 기존 해결 방식, 소요 시간·비용을 받는다.
- 공급자 조건 수락: 미확보. 샘플·검수자·실패 환불에 대한 찬반과 이유를 받는다.
- 원문 검토자: 미확보. 기간·행·단위·부호의 일치 또는 차이를 직접 답한다.
- 비교: 기존 방식과 이번 방식의 결과 정확도, 수동 검수 시간, 재시도 횟수, 총비용을 같은 작업에서 기록한다. 기억나지 않는 값은 미측정으로 남긴다.

외부 공급자가 수락하지 않거나 기존 도구가 충분하면 고객 가설을 수정한다. 기능 추가나 모의 거래 수 증가로 이 결론을 대신하지 않는다.
