[180초 한국어 자막 영상](../artifacts/dealtrace/film/dealtrace-3min.ko.webm) · [자막/SRT](../artifacts/dealtrace/film/captions.ko.srt) · [영상 manifest](../artifacts/dealtrace/film/video.json). 실제 공개 실행의 CUA 화면 12장을 편집한 무음 기록 재생이다. 실시간 거래 녹화가 아니다. 원본 픽셀과 캡처·렌더러·증거 해시를 보존하고 360프레임 전체 디코딩을 확인했다.

**오프닝:** “AI가 다른 AI에게 일을 맡길 때, 대화에서 무엇에 합의했는지 누가 증명할까요?”

청중은 외부 Agent에게 비동기 리서치 작업을 맡기는 작은 팀의 개발자다. 화면의 데이터 네 개는 큰 배치의 검수 가능한 최소 단위이며, 단순 숫자 추출을 유료로 외주 줘야 한다는 주장은 하지 않는다.

화면의 저장 기록 재생과 실시간 새 실행을 혼동하지 않는다. 가격 범위·공격 문구·오납품은 작성된 상황이고, 두 역할은 하나의 orchestrator에서 실행한다. 실제 외부 고객 거래나 독립 사업자 신원 인증으로 소개하지 않는다.

## 시연 중 문제가 생기면

- 모델·RPC를 재호출해서 성공한 척하지 않는다. 현재 실행 ID와 멈춘 이유를 보여준다.
- 이미 서명한 공개 거래가 대기 중이면 같은 run의 resume 명령으로 상태를 확인한다. 새 run으로 중복 지급하지 않는다.
- 저장된 성공 증거는 별도의 실행 ID를 밝히고 열 수 있다. 현재 실패 실행도 보존한다.

## 3분 후 초면 검토자에게 받을 답

설명이나 정답을 먼저 제공하지 않고 다음을 물어본다. 자동 QA 응답을 사람으로 세지 않는다.

1. 누가 어떤 문제 때문에 이 제품을 쓰나요?
2. 왜 Buyer AI가 다른 AI에게 작업을 맡기나요?
3. 왜 둘이 동의해도 바로 돈을 보낼 수 없나요?
4. 방금 본 거래 하나는 왜 지급·환불·차단됐나요?
5. 일반 에스크로와 무엇이 다른가요?

관찰 기록에는 시청한 run ID, 영상·UI 버전, 답변 원문, 정답을 유도했는지, 초면인지, 이해 실패 지점을 남긴다. 실제 사람 답변을 검토하기 전에는 이해도 성공으로 판정하지 않는다. 고객 수요와 지불 의사는 별도로 최근 실제 구매 사건을 통해 확인한다.
