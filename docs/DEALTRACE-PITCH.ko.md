# DealTrace 3분 발표

[180초 한국어 자막 영상](../artifacts/dealtrace/film-v3/dealtrace-3min.ko.webm) · [자막](../artifacts/dealtrace/film-v3/captions.ko.srt) · [원본 캡처와 검증 manifest](../artifacts/dealtrace/film-v3/video.json)

실제 공개 실행을 화면에서 재생해 캡처한 정지 화면 편집 영상이다. 무음이며 실시간 거래 녹화가 아니다. 원본 화면 pixel은 유지하고 아래에 자막을 붙인다.

| 시간 | 보여줄 것 | 말할 것 |
|---|---|---|
| 0–30초 | 예산/합의/청구; 작업 | “외부 AI에게 문서 처리를 맡긴 리서치 팀입니다. 예산이 남아 있어도 합의하지 않은 돈은 나가면 안 됩니다.” |
| 30–55초 | 대화, 원문 버튼, 서명 | “30에서 25, 다시 26. 납기는 10분에서 5분. 각 조건의 원문이 남고 두 Agent가 전체 거래를 확인합니다.” |
| 55–100초 | 31 청구, 잠긴 26, 지급 0 | “31도 40 안입니다. 하지만 합의는 26입니다. 진짜 Seller 서명이 있어도 틀린 청구는 차단합니다.” |
| 100–142초 | 정정 26 지급, 영수증·결과 다운로드 | “고쳐 청구하고 약속한 결과를 내면 딱 한 번 지급합니다. 다른 사람도 기록과 체인만으로 검증할 수 있습니다.” |
| 142–170초 | 의미 충돌, 오납품 환불, 다음 거래 제한 | “싼 다른 작업은 거절합니다. 오납품은 환불하고 같은 판매자의 다음 거래에는 샘플을 요구합니다.” |
| 170–180초 | 실제 사용량 | “AI는 의미 후보를 읽고, 코드는 돈의 경계를 지킵니다. 10번의 실제 호출, 129개 검사, 실제 테스트넷 지급과 환불입니다.” |

초면 검토자에게 ‘왜 31은 막혔나요?’, ‘왜 26은 지급됐나요?’, ‘어떤 원문과 서명으로 알 수 있나요?’를 물어본다. 자동 QA를 사용자 연구로 세지 않는다.

NPU 전력 절감, 외부 조직 인증, 일반 문서 정확도, 유료 수요는 검증되지 않았다. 실패 실행은 보존하고, 시연 중 문제가 나면 같은 run의 중단 이유를 보여준다. 새 공개 run으로 중복 지급하지 않는다.
