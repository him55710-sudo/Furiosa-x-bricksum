# GWDC Challenge B 기술 자료집

조사일: 2026-09-28 · 대상: 온체인·Kiln·NPU를 처음 배우며 백엔드를 준비하는 팀

**목표는 블록체인 전문가가 되는 것이 아니라, AI에게 준 지출 권한의 범위를 코드로 제한하고 그 결과를 다른 사람이 검증하게 만드는 것이다.**

기획 채팅 **「기획 GWDC 챌린지 시스템 아키텍처」**에 제공된 Challenge B 조건과 Control Memory 방향을 기준으로 만들었다. 논문은 설계 근거, 공식 문서는 구현 계약, 아래 아키텍처와 실험 절차는 우리 팀을 위한 제안이다. 이 자료집 자체는 구현·API 호출·체인 배포의 완료 증거가 아니다.

## 지금 확실히 구분할 것

- **Kiln은 Bricksum의 NPU 추론 API다.** 동명의 스테이킹 업체 Kiln, 과거 Ethereum Kiln 테스트넷과 다르다. [D01](https://kiln.bricksum.com/docs/en)
- **AI의 제안과 지출 권한은 분리한다.** 판매자 설명이나 AI 응답이 예산·허용 주소·기한을 바꿀 수 없어야 한다. 이 원칙을 우리의 구현 요구사항으로 채택한다.
- **해시 일치는 원본과의 일치 여부를 보여준다.** 원래 승인이 정당했는지, 상품이 배송됐는지까지 자동으로 증명하지 않는다. 서명·정책·실행 결과를 함께 검증하도록 설계한다.
- **NPU를 쓴다는 사실과 전력 절감률을 측정했다는 주장은 다르다.** 원격 API 사용량과 장치 전력은 별도 관측값이다. [P03](https://aclanthology.org/2025.acl-long.1563/)

## 현재 프로젝트 상태 갱신

사용자의 2026-09-28 모델 변경 지시에 따라 qwen3-32b로 연결했고 실제 추론이 성공했습니다. 현재 증거는 [Kiln 연결 명세](../docs/KILN-INTEGRATION.ko.md)를 따릅니다. 아래 GPT 가용성 설명과 원문 수집 기록은 모델 변경 전 조사 이력입니다. 원문 파일은 공개 저장소에 재배포하지 않습니다.

## 모델 변경 전 확인 사항

2026-09-28 조회한 [Kiln 모델 페이지](https://kiln.bricksum.com/docs/en/models)에는 `gpt-oss-120b`가 `coming soon`으로 표시되지만, 같은 문서의 샘플 및 대회 조건에는 해당 모델이 등장한다. 공개 페이지 상태만으로 계정별 실제 가용성을 단정하지 않는다. **대회 계정의 `GET /v1/models`와 실제 추론 성공 응답으로 확인할 때까지 모델 가용성·가격을 미확정으로 둔다.** 다른 모델을 임의로 사용하고 요건 충족으로 표시하면 안 된다.

## 스크랩 원칙과 범위

- Consensus에서 보안·추론 에너지·감사 로그를 검색하고, 인용한 검색 결과 4편 모두 `fetch`로 서지 정보를 확인했다. PagedAttention은 원 저자 arXiv에서 직접 확인했다.
- 학회·저자·공식 제품 문서로 교차 확인했다. Consensus의 저널 표기가 누락되거나 arXiv로만 나오는 경우 원 출판처 정보를 우선했다.
- 논문 5편의 공개 PDF와 Kiln 공식 Markdown 3개를 `archive/`에 수집했다. 실제 저장 성공 여부·크기·SHA-256은 [보관 목록](archive-manifest.json)에 기록한다.
- 논문 노트는 **초록·서지·공개 설명을 검토한 적용 중심 요약**이다. 모든 수식·실험을 정독하거나 재현했다는 뜻이 아니다. 정독할 위치와 남은 검증을 카드에 명시했다.
- 공개 원문은 원 출처의 저작권·라이선스를 따른다. 자료집에 전체 원문을 재출판하지 않고, 개인 학습용 보관과 링크·짧은 요약을 중심으로 사용한다.
- API 키, 개인키, 로그인 화면, 개인 대화 원문은 이 자료집에 수집하지 않는다.

## 완료 상태

자료 조사와 학습·구현 준비 문서는 작성했다. 실제 서비스의 완료 여부는 기획 채팅의 결과와 저장된 실행 증거로 별도 판정한다. 모델 응답, 거래 해시, 테스트 결과, 에너지 측정값을 예시 숫자로 채워 넣지 않는다.

기획 세션의 설계·진단 코드 작성 완료를 확인하고 반영했다. 자료집 Markdown 8개의 로컬 링크와 보관 파일 8개의 SHA-256을 검사했으며 오류는 없었다. 보관 원문은 합계 약 10.6 MB다. 실제 API 연결과 테스트넷 거래는 아직 완료 증거가 없다.
